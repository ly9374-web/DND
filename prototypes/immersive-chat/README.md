# 游戏聊天界面原型

直接打开 `index.html`，或双击 `打开聊天原型.command`。完全独立、离线可用；不接入正式游戏，不调用模型或生成服务。

- 默认网格背景；右上角「创作工具」可切换横图／竖图，或选本地图片。图片完整适配，默认只采样原图左右／上下边缘窄条，向外拉伸、模糊并渐变衔接；原图保持完整。可切回旧的整图模糊模式进行比较。
- 「视频」中选本地 MP4 / WebM 即模拟新视频生成完成，自动切到视频背景；支持静音、播放暂停及手动换回图片。
- 图片／视频模式聊天区默认占窗口高度的 1/6，展开按钮可临时放大；聊天、输入框、Story Brain 默认通栏显示，仅留少量边距；侧栏打开时为对应侧栏让位，背景始终全屏。
- Enter 发送，Shift + Enter 换行；骰子与撤回使用本地示例消息，消息悬停出现编辑按钮；助手消息也提供浏览器朗读（此原型使用系统语音，正式版仍保留现有音频能力）。
- 聊天历史滚到底后，同一次手势的惯性会被挡在边界；停下后再推一次，或在输入框上开始一次向下滚动，露出输入框下方的 Story Brain。向上滚时先收起 Brain，并停在输入框归位的位置；下一次手势再滚历史。也可点击输入框下方的文字展开。双击 Brain 文字可编辑。
- 右上角铅笔进入布局编辑：圆形图标把手拖动，各元素右下角缩放。输入框、撤回、骰子、聊天区、顶部按钮组、展开按钮、抽屉等可分别调整。选中把手后方向键微调，Shift 加速。抽屉打开后才能调整；Brain 展开后才能调整。
- 网格／媒体两种状态独立保存布局。修改自动保存在当前浏览器；顶部「导出」始终可见，会导出两种布局、偏好设置、窗口大小和当前元素坐标；将 JSON 发回即可据此继续修改。「布局」标签可手动保存、导入 JSON、恢复默认。只保存界面布局与阅读偏好，不保存所选媒体、聊天与 Brain 的修改。
- 左侧抽屉里的游戏设置只是视觉占位；本原型没有修改正式设置功能。字号、蒙版、侧栏宽度为可用的预览设置。

桌面横屏优先。小于 900px 时只同时打开一个抽屉；小于 850px 时优先保证聊天阅读宽度，抽屉可能覆盖部分聊天，建议使用宽窗口评审。

内置场景为本文件内的 SVG 示意图，无外部资源依赖。可换入真实生成图片观察融合效果。

本轮新增：

- ⌘Z / Ctrl+Z 撤销一次完整拖动、缩放、阅读设置或消息修改；⇧⌘Z / Ctrl+Shift+Z 重做。文字输入时保留文本框自身的撤销。顶部也有撤销／重做按钮。撤销记录只在当前打开期间保留，刷新后清空；已保存布局不会清空。
- 左侧「文字对比」可选当前蒙版、自动黑白字、固定白字、固定黑字。自动模式采样聊天所在区域，并为视频限制切换频率、增加阈值缓冲；默认继续使用原有蒙版。局部明暗交错的图片仍建议保留蒙版。
- 「纯文字」开关可隐藏底部蒙版和输入框底色，观察纯透明效果。
- 场景中增加纯黑测试图与生成的明亮白天海港。白天图通过内置 image_gen 生成，源图和提示词保存在 `assets/`，并已内嵌进 HTML，单独复制 HTML 也能离线使用。
- 视频边缘延展直接采样当前画面，无需拆分或转码文件。边缘渲染以低分辨率约 10fps 更新，主视频保持正常播放。
- 导出不会自动上传文件，也不包含用户所选的本地媒体文件。自动保存在浏览器中的数据不会自行发送给开发者。

第三轮外观调整：

- 移除输入框下方的 Enter / Shift+Enter 提示，键盘操作保持可用。
- 蒙版改为默认 42% 的半透明灰黑色，分多段缓慢过渡到完全透明。蒙版顶部跟随聊天区域的实际顶部，拉高、拖动、缩放或展开 Story Brain 时同步更新。自动黑字模式使用同样柔和的浅灰蒙版。
- 聊天记录、输入框和 Story Brain 改为通栏，桌面左右各 14px、小窗口各 10px 边距。
- 首次打开此版本会清理旧布局中这几个通栏区域的横向偏移和固定宽度，保留高度、纵向位置以及按钮的调整。之后的布局调整继续保存和导出。

第四轮字体实验：左侧「文字对比」新增「自动撞色 · 互补色文字」。从整张图片的色相分布选主色，取互补色；再根据聊天所在区域的亮度调整文字深浅。视频定期更新。灰度背景没有明确色相时退回浅／深中性色。可在设置中看到主色和最终字体颜色；这一选择同样支持保存、导出和撤销。

配色设置刷新：自动撞色现为默认文字模式。旧版本已保存的配色选择会在下次打开时重置一次，同时保留布局与其他设置；重置完成后，用户主动切换的文字模式仍会正常保存。已用非内置的本地蓝色、绿色测试图片验证换图会重新分析像素并得到不同字色。

阅读底板实验：聊天记录和 Story Brain 文字后方新增统一的半透明底板，默认开启、不透明度 68%，并模糊后方背景 14px。浅色字使用深灰底板，深色字使用浅灰底板。左侧「文字底板」可开关，「底板不透明度」可调整；支持保存、导出、导入及撤销。整页渐变蒙版可单独开关，不影响文字底板。

最新调整（取代阅读底板实验）：已删除文字底板与相应控制。左侧「蒙版高度」按屏幕高度 20%～100% 调整底部蒙版范围，默认 70%，支持保存、导入／导出和撤销；「蒙版不透明度」单独控制浓度。渐变从下往上先缓慢、再加速变透明，让浅色蒙版覆盖更多阅读区域。侧栏打开后聊天进一步收窄，已有的固定宽度和横向偏移也会临时约束在中间，关闭侧栏后恢复。

真实对话预览：打开 `真实对话预览.html` 或 `打开真实对话预览.command`。使用用户提供的 `游戏聊天页-布局.json` 原样还原布局与显示偏好；包含日志中最新聊天请求对应的实际回复、最近三轮消息、对应本地原图和短期 Story Brain。默认滚到最新回复。原图已嵌入 HTML，可离线打开。此页面使用独立的浏览器保存键，不覆盖原型中的调整；修改仅影响预览，发送和骰子不连接游戏或模型。来源记录在 `真实对话预览-来源.json`，原始布局副本在 `真实对话预览-布局.json`。

真实对话预览的抽屉调整：

- 移除画面里的「故事记录」标题和「向下滚动 · Story Brain」提示，保留滚动展开／收回 Story Brain 的操作。
- 左侧按正式页面的控件重新排布：返回／新建对话、最终设定、System Prompt 入口、上下文轮数、聊天及记忆模型／思考、更新间隔、音色、生图轮询、temperature、意外情况、自动生图。当前值来自本地用户设置的明确白名单，未复制 API 密钥或 System Prompt 正文。
- 左侧界面选项仅保留蒙版高度与不透明度，其余原型外观调节隐藏。
- 右侧按正式页面整理图片 prompt 模式、主体、provider、quality、refiner、尺寸、参考图片／上传／URL、视频模型／时长／声音／分辨率／prompt、一键流程、网址收藏及媒体记录。生成与正式存储操作仅是预览入口，不调用模型，不修改正式数据。
- 最下面的背景记录选择器第一项为「无图片／正常背景」，选中后使用网格背景；选回记录可重新展示。单独的展示开关可暂时隐藏选中媒体。空选择及本页控件修改会保存在这份预览自己的浏览器存储中。

真实预览最新六项调整：两侧抽屉删除冗余标题、说明和「对话」小节标题；保留实际设置控件。底部蒙版在下方 80% 保持所设不透明度，仅顶部 20% 渐隐；蒙版高度、浓度滑块仍可用，旧的隐藏整页蒙版状态会取消。原聊天区上方两个图标隐藏，改为悬停上沿出现上下箭头，可直接拖动高度（无需进入布局编辑），也支持键盘方向键、保存和撤销。Story Brain 上滑内容至顶部时，同一次滚动惯性停住；停顿后重新上滑才收起，收起后同一手势不会继续翻聊天。输入框统一距窗口底部 6px，有图／无图切换不会再移动；展开 Brain 时仍随之上移。无媒体时背景采用正式主页的蓝光细网格、大网格与流动高光。

蒙版与聊天区域联动：蒙版上沿现在始终对齐聊天记录区上沿；拖动聊天区高度、展开／收起 Story Brain、切换有图／无图和调整窗口时同步更新。原「蒙版高度」滑块改为「聊天与蒙版高度」，调整它也同时改变聊天区高度，不再形成两个独立范围。顶部 20% 渐隐规则保留。

侧栏材质：左侧改为高透明液态玻璃，使用低浓度底色、9px 背景模糊、增饱和、斜向反光和内侧高光边；右侧改为 70% 透明（30% 底色）的毛玻璃，使用 28px 背景模糊。控件底色同步减淡，亮背景下文字保持深色以便阅读。

两侧统一为更透明液态玻璃：CSS 常数 `--sidebar-glass-base-alpha: .04`（底色 4% 不透明，即 96% 透明）；高光 `.065`、中部 `.008`、冷色边光 `.025`；底色与高光叠加后的材质透明度约 89.8%～95.2%。背景模糊统一 6px。控件底色 alpha `.075`，边缘与文字保留独立对比度。
