# DND

## 一、使用说明与功能

DND 是在自己电脑上运行的 AI 故事工具，可以聊天、扮演角色、续写剧情，并为故事生成图片、视频和语音。首页点“开始”新建故事，点“继续”接着写，点“记录”查看历史内容。

游戏界面：点“开始”或“继续”后进入沉浸式页面，图片／视频完整铺设为背景，左右液态玻璃抽屉分别放游戏设置和媒体工具。右侧“背景展示”可选“无图片／正常背景”，继续游戏时恢复上次的背景选择；新生成的图片／视频会自动成为背景。背景视频默认静音，可在顶部暂停或开启声音。

聊天区域每次打开默认占窗口高度的一半，把鼠标移到聊天区最上沿，可上下拖动高度；该高度不保存。蒙版与聊天区上沿对齐，仅顶部 8% 渐隐，左侧可调节不透明度。聊天记录与 Story Brain 各自独立滚动，到边界停止。只有在输入框上向下滑动才展开 Story Brain，向上滑动收起。聊天先显示最近 6 轮，滚到顶部时每次补载前 6 轮并保留阅读位置；完整存档和模型上下文不受影响。设置与媒体工具首次打开时加载。双击记忆文字可编辑，消息悬停可编辑或生成语音。输入框右侧为撤回和掷骰，Enter 发送、Shift+Enter 换行。

创建世界书：进入首页“prompt”，切换到“世界书”，点“新建”。选择模型，用几句话介绍世界背景，例如时代、地点、势力和规则，再点“生成”。AI 会提出细化问题，你可以回答后生成，也可以跳过。生成后可以修改，记得填写名称并保存。

创建角色卡：切换到“角色卡”，点“新建”，填写角色身份、性格、与用户角色的关系等，再按提示生成。你扮演的人物和其他主要人物可以分别建卡，生成后填写角色名称并保存。

创建最终 prompt：切换到“最终设定”，点“新建”，选择固定模板、世界书、长期记忆、用户角色和其他角色，点“确定”即可组合成最终 prompt。缺少的素材先到对应页面创建。检查内容、填写名称并保存，再回到“开始”，在侧边栏选择这份最终设定和聊天模型，就能开始故事。

事件：在 Prompt 的“最终设定”编辑标题右侧点击“生成事件”，固定两轮生成。第一轮使用 DeepSeek Flash、不思考，展示8道四选一问题，下方可自由回答；第二轮沿用当前生成模型、开启思考，在一次回复中生成约1000字的未来4天故事背景和5个场景事件、5个时间事件。两轮 temperature 均为0.8。结果可预览、修改故事背景后确定，也可保留答案重新生成第二轮，或取消而不改动原方案。首轮输入下的“事件”栏目默认收起，展开后可独立选择方案、编辑地点表述和事件内容、增删或停用；地点表述为普通文字，匹配时自动忽略“的”和空格；删除单条事件会先弹窗确认。收起不会停用。新游戏复制所选方案；模板后续修改不影响已有游戏。地点和时间读取上一轮回复末尾的“当前时间／当前地点”，命中后在下一轮后台注入【特殊事件】，前台用户消息不显示。跳过多个时间点会按先后一次注入所有已到点且未消费的事件。隐藏内容也供聊天上下文和 Story Brain 更新读取；成功问答只消费一次，撤回会恢复触发资格，分支各自独立。

生成图片：先让 AI 写出一段剧情，再到右侧点“生成图片prompt”。可以修改画面描述，选择图片模型和比例，需要时添加参考图，最后点“生成图片”。

生成视频：在“图生视频”区域选择模型和时长。程序优先使用最后选中的参考图，否则使用最新生成的图片。点“生视频prompt”，检查或修改动作、镜头描述，再点“生视频”。也可以点“一键生成”，自动准备图片和视频 prompt，完成后仍需手动点“生视频”。

## 二、API Key 怎么填

首页打开“APIkey”，按需填写，不必全部配置。

DeepSeek、Grok 聊天 Key 用于各自的文字模型；keylink 是可选的 DeepSeek 转接服务。

Grok 生图 Key 用于 Grok 图片；Replicate Token 用于该平台图片和 Wan 2.2 视频；OpenRouter Key 用于 Mistral / Gemini 聊天、Seedance 和 Wan 3.0 视频。

DashScope Key 用于语音。Cloudinary Key 和 Secret 需一起填写，用于大图临时上传。

不填某项就不能使用对应服务；全部不填仍可整理设定、查看记录，但不能调用 AI 生成。API 费用由对应平台收取。

## 三、如何下载和使用

打开 [DND 项目页](https://github.com/ly9374-web/DND)，点 Code，再点 Download ZIP，下载并解压。安装 Python 3.10 以上版本，推荐 3.12；Windows 安装时勾选 Add Python to PATH。

Mac 双击“启动普通模式.command”。首次若被拦截，点击左上角苹果按钮，进入“系统设置”，找到“隐私与安全性”，向下滚动，点[“仍要打开”](https://support.apple.com/zh-cn/102445)并确认。Windows 双击“启动普通模式.bat”。

首次会联网安装组件，等待浏览器打开即可，使用期间保留启动窗口。也可以直接让能操作电脑的 AI 帮你安装并打开。
